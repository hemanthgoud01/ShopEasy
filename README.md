# ShopEasy

A full-stack E-commerce web application built using Django and MySQL.

## Features

- User Authentication
- Product Management
- Shopping Cart
- Checkout
- Razorpay Payment
- Order Tracking
- Admin Dashboard
- Bootstrap UI

## Technologies

- Python
- Django
- MySQL
- Bootstrap
- HTML
- CSS
- JavaScript

## Installation

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
